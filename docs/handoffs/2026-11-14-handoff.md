## Implemented behavior

- Single Rust executable, supported Rust 1.88, targeting TrueNAS SCALE 25.04.2.x with observed 25.04.2.6 evidence. Reference exporter tested against 25.10.2 is inspiration only. Official middleware pin: 244b717370fe35fb9eefc3096acfbc25f12b57b6 (TS-25.04.2.6).
- Default mode authenticates and polls pool.query. Pool metrics: capacity/allocated/free, healthy/warning, bounded status/status_code, fragmentation. Scan content is currently ignored.
- TRUENAS_SYSTEM_ENABLED=false by default. True adds system.info gate on every connection/reconnect before connected/request admission, scheduled identity/version/uptime/physical-total/load data and separate required freshness. Pool-only mode does not automatically discover/gate version.
- TRUENAS_REALTIME_ENABLED=false by default and requires system mode. Adds a second independently authenticated/version-gated socket per target and exact reporting.realtime subscription. CPU, physical available memory, network and ARC have independent latest snapshots/freshness. Optional ARC ratios do not invalidate a valid ARC-size sample. Total physical memory is emitted only from system.info.
- 1..16 targets, isolated credential/CA/client/scheduler/error/cache state. Readiness requires all enabled required groups on all targets. A bad target does not erase valid sibling-target metrics.
- Poll default 60s, API timeout 10s, pool/system TTL 3 polls; realtime interval 2s (2..300), TTL 3 intervals (>interval, <=86400). Check current configuration.md/code for exact limits.
- Verified WSS cannot be disabled. Typed allowlist: auth.login_ex, pool.query, system.info, exact core.subscribe and connection-owned core.unsubscribe. No method discovery/free-form event configuration.
- Cached HTTP only: /metrics never calls the NAS; /healthz is liveness; /readyz is freshness/compatibility. One active encoding job, expected 503 encoder-busy responses for overlapping encoding; health/readiness remain independent.
- Failed collection never refreshes last success. Retain last good data only through finite monotonic TTL; expired measurements disappear. Missing optional values are absent. A producer-supplied zero may already have lost availability provenance.
- Bounded requests/frames/cardinality/pre-ACK latest event; capped jittered retries, silence expiry despite pongs, owned unsubscribe with bounded cleanup and SIGINT/SIGTERM HTTP drain. Logs are redacted even under trace.
- Mock mode is explicitly synthetic, makes no NAS connections and keeps API-connected/compatible/subscribed zero. Synthetic readiness can still become true.
- Non-root UID/GID 10001:10001 distroless runtime; no shell/package manager. Builder/base digests pinned. Use healthcheck/logs/metrics; do not exec sh or add debug tools to production runtime.
